# AshenAI

A local AI app for Windows: chat, work agent and image studio that run on your own PC.

## Install

**Step 1.** Open **Releases** (right side of this page) and download the latest `AshenAI_<version>.zip`.

**Step 2.** Extract it to a normal folder you can write to (for example `Documents\AshenAI`). Don't run it from inside the ZIP or from Program Files.

**Step 3.** Run `Start AshenAI.bat`. Choose the models you want in **Settings**; nothing large is downloaded without your choice.

## Updates

AshenAI checks for new versions itself. When a dot appears on **Settings**, open **Application updates** and click **Download and install**, then **Update and restart**. Your chats, settings and models are kept, and if an update fails the previous version is restored.

Every release is signed. AshenAI only installs updates signed by the same publisher.

This repository only hosts releases.
